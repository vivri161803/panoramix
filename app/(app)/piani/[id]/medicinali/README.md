# medicinali

## Overview
Medication pages within a plan (`/piani/[id]/medicinali/...`).

## Subdirectories & Boundaries
- [medId]: [./[medId]/README.md](./[medId]/README.md) - edit an existing medication and its dose changes; contains `storico` (stock history).
- nuovo: [./nuovo/README.md](./nuovo/README.md) - add a medication to the plan.
